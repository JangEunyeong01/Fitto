피또 계정과 데이터 삭제

시행일 2026년 10월 7일

앱에서 지우기

  • 계정째 지우기: 설정 > 계정 > 탈퇴. 비밀번호를 한 번 더 확인하고 바로 지워요.
  • 계정은 두고 기록만 지우기: 설정 > 데이터 초기화
  • 생리 기록만 지우기: 생리 설정 > 생리 데이터 삭제

앱 없이 요청하기

앱을 지웠거나 로그인할 수 없으면 가입한 이메일로 fitto.team.kr@gmail.com에 "계정 삭제 요청"이라고 보내 주세요. 가입한 이메일에서 온 요청인지 확인한 뒤 10일 안에 지우고 알려 드려요.

지워지는 것

계정(이메일, 비밀번호, 프로필)과 서버에 저장된 모든 기록(식단, 운동, 물, 걸음, 체중, 생리, 레시피, 루틴, 직접 입력한 재료)이 지워져요. 되살릴 수 없어요.

잠시 남는 것

  • 데이터베이스 업체의 장애 복구용 기록: 최대 7일 뒤 자동 삭제
  • 보안 기록(접속 IP, 일부를 가린 이메일): 7일 뒤 자동 삭제
  • 탈퇴 사유: 누가 떠났는지 알 수 없게(사유와 날짜만) 남아요

기기에 남은 기록

계정 없이 쓴 기록과 레시피 사진은 서버에 없고 휴대폰에만 있어요. 앱을 지우면 함께 지워져요.
